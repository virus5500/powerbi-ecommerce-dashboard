# Power BI Ecommerce Sales Dashboard

## Tools Used
- Power BI Desktop
- Excel
- DAX

## Dashboard Features
- Total Sales KPI
- Category-wise Sales Analysis
- City-wise interactive slicer
- Dynamic visuals using DAX measures

## Project Structure
- Dataset: Excel dataset
- Dashboard: Power BI (.pbix) file
- Screenshots: Dashboard preview

## Use Case
Sales performance analysis by category and city.
