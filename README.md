# E-commerce Sales Dashboard (Power BI)

This project showcases an interactive Power BI dashboard
built using retail sales data.

## Features
- Total Sales KPI
- Category-wise sales analysis
- City-wise revenue analysis
- Top-selling products
- Interactive slicers

## Tools Used
- Power BI
- Excel
- DAX

## Power BI Ecommerce Sales Dashboard

### Tools Used
- Power BI Desktop
- Excel
- DAX

### Dashboard Features
- Total Sales KPI
- Category-wise Sales Analysis
- City-wise interactive slicer
